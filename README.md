# 進度予定表（shindo-yoteihyo）

先生方の週ごとの授業進度予定・実施状況を管理するための Excel（マクロ有効ブック）です。
どなたでも自由にダウンロードしてお使いいただけます。

## ダウンロード

👉 **[進度予定表.xlsm をダウンロード](https://github.com/edu-tools-jp/shindo-yoteihyo/raw/main/%E9%80%B2%E5%BA%A6%E4%BA%88%E5%AE%9A%E8%A1%A8.xlsm)**

（リンクをクリックするとファイルが直接ダウンロードされます。うまくいかない場合は、ファイル一覧の `進度予定表.xlsm` を開き、右上の「Download raw file（↓）」ボタンを押してください。）

## シート構成

| シート | 内容 |
| --- | --- |
| 基本設定 | 年度・担当教科・担当クラス・特別活動・週コマ数・長期休業期間などを入力 |
| 時間割マスター | 曜日×校時の時間割をプルダウンでクラス選択して作成 |
| 週案_テンプレート | 週ごとの進度予定表（予定／授業後・実施/予定・累計の集計、決裁欄つき） |

## 使い方

1. ダウンロードしたファイルを Excel（Windows 版推奨）で開きます。
2. マクロを使用しているため、開いたときに表示される **「コンテンツの有効化」** を押してください。
   - 「このファイルのソースが信頼できないため、マクロの実行がブロックされました」と表示される場合は、
     ファイルを右クリック →「プロパティ」→ 下部の **「許可する」** にチェック →「OK」をしてから開き直してください。
3. 「基本設定」シートに年度・担当教科・担当クラスなどを入力します。
4. 「時間割マスター」シートで時間割を設定します。
5. 「週案_テンプレート」で週ごとの予定を作成します。

## 動作環境

- Microsoft Excel（Windows 版、Microsoft 365 / Excel 2016 以降を想定）
- マクロ（VBA）を使用するため、Excel Online・Mac 版・Google スプレッドシート等では一部機能が動作しない場合があります。
